Parallelizing a quantum computation simulator

15-418 Course Project

Ayush Garg · 15-418 · Fall 2026

Summary

My goal is to parallelize the simulation of a quantum computer using GPUs, focusing on speeding up state-vector updates and scheduling computations effectively. I plan to write a simulator in C++ and CUDA, compare it with a sequential implementation, and use Qiskit to check correctness.

Project goals

  • Implement a sequential state-vector simulator and benchmark circuits.
  • Parallelize amplitude updates using CUDA.
  • Explore gate fusion and independent qubit-group evaluation.
  • Measure performance across qubit counts and circuit lengths.

I hope to demonstrate a small instance of Shor's algorithm, such as factoring 119, if the circuit fits within the available memory. Multi-device simulation is a stretch goal. The proposed 100–250× speedup is a target relative to my sequential implementation, not a measured result.
